# Projects

## Playlistation

[playlistation.com](https://playlistation.com) · smart playlists for Spotify.

You describe a playlist with rules (genre, artist, tempo, energy, language, release date, how recently you liked a track…) and Playlistation builds it from your liked songs and keeps it up to date on its own. Solo project, in production, maintained.

Under the hood: a Symfony API, a React app, MongoDB, RabbitMQ workers and a Next.js site with the [docs](https://playlistation.com/doc).
